# Barbermaxxing трекер

Telegram Mini App для учеников программы Barbermaxxing.

- `index.html` — приложение: вход через Telegram, админка с приглашениями
- `supabase/` — схема базы, права, функции входа и админа, тесты
- `scripts/deploy.sh` — выкладка в Supabase
- `prototype/today.html` — демо экрана «Сегодня»
- `assets/` — фон и картинки
