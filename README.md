# Barbermaxxing трекер

Telegram Mini App для учеников программы Barbermaxxing.

- `index.html`, `css/`, `js/` — приложение (ученик и админка)
- `supabase/` — схема базы, права, функции входа, админа, бота и напоминаний, тесты
- `scripts/` — выкладка в Supabase и настройка бота
- `tests/` — тесты расчётов и сквозные проверки
- `docs/TZ.md` — полное ТЗ, `docs/RUNBOOK.md` — запуск и проверка на устройствах
- `prototype/today.html` — одобренный демо-экран «Сегодня»
